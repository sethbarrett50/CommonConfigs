---
name: Workflow safety
---

- Default to read-first behavior.
- For non-trivial tasks, inspect relevant files before proposing edits.
- Prefer Plan mode behavior first: explain the intended changes before editing.
- Keep changes scoped to the smallest set of files that fully solves the task.
- Do not make unrelated cleanup changes.
- Do not rewrite working code for style alone.
- Before editing, identify the exact files to change and the reason for each change.
- After editing, summarize what changed and any follow-up checks that should be run.
